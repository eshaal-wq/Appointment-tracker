 DocTracker - Doctor Appointment Tracker

A simple, offline doctor appointment tracker built in a single HTML file. Perfect for managing your medical visits without any internet or backend.

 Live Demo
https://eshaal-wq.github.io/Appointment-tracker/

 Features
 Add appointments with doctor name, date, time & notes
 View all upcoming appointments in a clean list
 Delete past / cancelled appointments
 Auto-saves in browser using LocalStorage (no database needed)
 100% responsive & works offline
  Zero dependencies - just one `index.html` file

 How To Use
1. Clone or download this repo
2. Open `index.html` in any browser / VS Code
3. Start adding your appointments!

 Tech Stack
- HTML5
- CSS3 (Modern responsive design)
- Vanilla JavaScript
- LocalStorage API
